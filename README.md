# MD2Blog

Markdown으로 작성한 글을 블로그 에디터에 붙여넣기 좋은 HTML로 변환하고, 개인 Markdown 페이지를 계층적으로 관리할 수 있는 웹 도구입니다.

서비스 바로가기: https://md2blog.pages.dev

## 주요 기능

- Markdown 파일 업로드 및 미리보기
- Mermaid 코드 블록 다이어그램 렌더링 및 개별 PNG 이미지 복사
- 미리보기 HTML을 클립보드에 복사
- HTML 파일 다운로드
- PDF 파일 다운로드
- 블로그 에디터용 빈 줄 보정
- 네이버 블로그에 최적화된 코드블록 변환
- H2 목차 자동 생성 및 H2 구분선 추가
- 첫 번째 H1 제외
- HTML 미리보기/다운로드 결과의 플로팅 섹션 내비게이션
- 로그인 없이 사용하는 임시 Markdown 페이지
- 임시 페이지 IndexedDB 자동 저장 및 실시간 미리보기
- 빠른 변환 내용을 임시 페이지에 교체하거나 추가
- 회원가입, 로그인, JWT 인증 및 Refresh Token 세션
- 사용자별 Markdown 페이지 생성, 수정, 휴지통 이동 및 자동 저장
- 하위 페이지 생성과 드래그 앤 드롭 이동·정렬
- 빠른 변환 내용을 회원 기록장의 새 페이지 또는 기존 페이지에 저장
- Markdown 편집기와 미리보기 너비 조절

## 변환 모드

| 모드 | 설명 |
|---|---|
| 표준 변환 | 일반적인 문서에 적합한 기본 스타일로 변환합니다. |
| 빈 줄 추가 | 블로그 에디터에서 문단 간격이 유지되도록 빈 줄을 추가합니다. |
| 네이버 블로그 | 네이버 에디터에 최적화된 코드블록 스타일을 적용합니다. |

변환 모드와 추가 옵션은 선택 즉시 미리보기, 복사 및 다운로드 결과에 반영됩니다.

## 비회원 임시 기록장

- 비회원은 `내 기록장`에서 임시 페이지 한 개를 사용할 수 있습니다.
- 페이지명은 `임시 페이지`로 고정됩니다.
- 작성 내용은 현재 브라우저의 IndexedDB에 자동 저장됩니다.
- 다른 브라우저나 기기와 동기화되지 않으며, 브라우저 데이터를 삭제하면 내용이 사라질 수 있습니다.
- 로그인하면 빠른 변환의 내용을 사용자 기록장에 저장할 수 있습니다.

## 회원 기록장

- 로그인 사용자의 페이지는 Neon PostgreSQL에 저장되어 브라우저와 기기 간에 동기화됩니다.
- 최상위 페이지와 하위 페이지를 생성하고 계층 및 순서를 자유롭게 변경할 수 있습니다.
- 페이지 제목과 Markdown 본문은 자동 저장됩니다.
- 페이지 목록은 메타데이터만 조회하고, 본문은 페이지를 선택할 때 별도로 불러옵니다.
- 삭제한 페이지와 하위 페이지는 휴지통에서 복원할 수 있으며 삭제일로부터 30일 후 영구 삭제됩니다.
- 한 번 조회한 본문은 현재 화면에서 다시 사용할 수 있도록 메모리에 캐시합니다.

페이지 메타데이터는 `pages`, Markdown 본문은 `page_contents` 테이블에 분리하여 저장합니다.

## 개발

```bash
npm install
cp .env.example .env.local
npm run dev
```

개발 서버가 실행되면 브라우저에서 `http://localhost:5173/`을 열어 사용합니다.

`VITE_API_BASE_URL`에는 FastAPI 기본 주소를 설정합니다. `VITE_` 접두사가 붙은
값은 브라우저 번들에 포함되므로 비밀번호나 API 비밀 값은 저장하지 않습니다.

## 테스트

```bash
npm test
```

개발 중 테스트를 감시 모드로 실행하려면 `npm run test:watch`를 사용합니다.

## 빌드

```bash
npm run build
```

정적 파일은 `dist/`에 생성됩니다.

## Python CLI

`python-cli/`는 웹 앱 이전에 만든 CLI 버전입니다.

현재 주요 기능은 웹 앱을 기준으로 개발하고 있으며, CLI는 로컬에서 단일 Markdown 파일을 HTML로 변환할 때 사용할 수 있습니다.
