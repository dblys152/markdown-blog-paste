# MD2Blog 수동 회귀 체크리스트

브라우저 권한, Canvas, iframe, 외부 블로그 에디터에 의존하는 기능은 배포 전 아래 항목을 직접 확인합니다.

## 미리보기와 Mermaid

- [ ] 샘플 Markdown을 열면 Mermaid 다이어그램이 정상적으로 렌더링된다.
- [ ] 잘못된 Mermaid 문법은 원본 코드블록과 오류 표시를 유지한다.
- [ ] Mermaid 영역의 복사 아이콘이 다이어그램 오른쪽 위에 표시된다.
- [ ] 복사 아이콘에 마우스를 올리면 `PNG 이미지 복사` 안내가 표시된다.
- [ ] 복사 아이콘을 누르면 PNG 이미지가 클립보드에 저장된다.
- [ ] 복사한 PNG를 이미지 편집기나 지원되는 블로그 에디터에 붙여넣을 수 있다.

## 미리보기 내용 복사

- [ ] 일반 본문, 제목, 목록, 표, 코드블록이 서식을 유지한 채 복사된다.
- [ ] Mermaid 이미지는 전체 복사 결과에서 제외된다.
- [ ] Mermaid 위치에는 번호가 포함된 자리 표시자가 들어간다.
- [ ] 티스토리에 붙여넣을 때 본문이 정상적으로 표시된다.
- [ ] `네이버 블로그` 모드의 결과를 네이버 블로그에 붙여넣을 수 있다.
- [ ] Notion에 붙여넣을 때 용량 초과 오류가 발생하지 않는다.

## 다운로드

- [ ] HTML 다운로드 파일을 브라우저에서 열 수 있다.
- [ ] HTML 파일에 Mermaid 다이어그램과 플로팅 목차가 표시된다.
- [ ] PDF 다운로드가 완료되고 페이지가 잘리지 않는다.
- [ ] PDF 파일에 Mermaid 다이어그램이 표시된다.

## 화면과 내비게이션

- [ ] `표준 변환`, `빈 줄 추가`, `네이버 블로그` 모드를 변경하면 결과가 즉시 갱신된다.
- [ ] 첫 번째 H1 제외, H2 목차 자동 생성, H2 구분선 옵션이 즉시 반영된다.
- [ ] HTML 미리보기의 플로팅 목차가 올바른 제목으로 이동한다.
- [ ] 모바일 너비에서 주요 작업 버튼과 미리보기를 사용할 수 있다.

## 비회원 임시 기록장

- [ ] `내 기록장`에 처음 진입하면 `임시 페이지` 한 개가 표시된다.
- [ ] 페이지명은 업로드 파일명이나 첫 번째 H1으로 변경되지 않고 `임시 페이지`로 유지된다.
- [ ] Markdown을 수정하면 현재 브라우저의 IndexedDB에 자동 저장된다.
- [ ] 새로고침 후 저장된 Markdown이 복원된다.
- [ ] `모든 페이지`, `최근 변경`, 페이지별 작업 메뉴는 표시되지 않는다.
- [ ] 페이지 영역의 `+` 버튼과 임시 페이지 안내 링크가 로그인 화면으로 이동한다.

## 빠른 변환에서 기록장에 저장

- [ ] `기록장에 저장`을 누르면 즉시 저장되지 않고 저장 방식 팝업이 열린다.
- [ ] 팝업 제목이 `기록장에 저장`으로 표시된다.
- [ ] `임시 페이지를 현재 내용으로 교체`가 기본 선택된다.
- [ ] 기존 임시 내용이 있을 때 교체 경고가 표시된다.
- [ ] 교체 저장은 Markdown 본문만 교체하고 페이지명은 `임시 페이지`로 유지한다.
- [ ] 내용 추가는 기존 본문 뒤에 현재 Markdown을 이어 붙인다.
- [ ] 취소하면 기존 임시 페이지가 변경되지 않는다.
- [ ] 로그인 사용자는 새 페이지 또는 기존 페이지를 저장 대상으로 선택할 수 있다.
- [ ] 기존 페이지에 `내용 추가`로 저장하면 기존 본문 뒤에 현재 Markdown이 추가된다.

## 회원 기록장

- [ ] 로그인 후 `내 기록장`에 진입하면 임시 페이지 화면이 먼저 표시되지 않는다.
- [ ] 페이지 목록이 많아지면 사이드바 헤더는 유지되고 목록 영역에만 스크롤이 생긴다.
- [ ] 페이지 행의 제목 바깥을 클릭해도 해당 페이지 상세가 열린다.
- [ ] 페이지 목록 하단의 `⋮` 메뉴는 위쪽으로 열려 화면 밖으로 잘리지 않는다.
- [ ] 최상위 페이지와 하위 페이지를 생성할 수 있다.
- [ ] 페이지 이름을 변경하면 목록과 편집기 헤더에 함께 반영된다.
- [ ] 하위 페이지가 없는 페이지 삭제 안내에는 하위 페이지 문구가 표시되지 않는다.
- [ ] 하위 페이지가 있는 페이지를 삭제하면 모든 하위 페이지 삭제를 안내한다.
- [ ] 페이지를 드래그 앤 드롭하여 같은 계층의 순서와 상위 페이지를 변경할 수 있다.
- [ ] 페이지 제목과 Markdown 본문을 수정하면 자동 저장 상태가 표시된다.
- [ ] 새로고침 후 저장한 페이지 제목, 본문, 계층 및 순서가 복원된다.
- [ ] 다른 페이지를 처음 선택할 때 상세 API로 본문을 불러온다.
- [ ] 이미 조회한 페이지를 다시 선택하면 저장되지 않은 다른 페이지 내용이 섞이지 않는다.
- [ ] 페이지를 삭제하면 해당 페이지의 본문도 함께 삭제된다.

## 기록장 편집 화면

- [ ] 구분선을 좌우로 드래그하면 에디터와 미리보기 너비가 변경된다.
- [ ] 구분선이 양쪽 콘텐츠의 최소 너비를 침범하지 않는다.
- [ ] 구분선에 포커스한 뒤 좌우 방향키로 너비를 조절할 수 있다.
- [ ] 구분선을 더블 클릭하면 기본 비율로 돌아간다.
- [ ] 새로고침 후 마지막으로 조절한 비율이 복원된다.
- [ ] 리사이즈 후 Markdown 입력창과 미리보기 영역이 각각 정상적으로 스크롤된다.
